# Patent promise for the .are format

Aureality (and the company that will hold its rights once registered) promises not to sue anyone for infringing any patent it owns or controls, now or in the future, for making, using, selling, distributing or otherwise implementing software, hardware or services that read, write, convert, validate or display `.are` files as described in any published version of the `.are` specification.

This promise:

- applies to everyone, worldwide, free of charge, with no need to sign or register;
- covers only what is needed to implement the specification, not unrelated features of a product;
- cannot be withdrawn for versions of the specification already published;
- ends for a party that first sues Aureality or any `.are` implementer for patent infringement over an implementation of `.are` (a defensive termination clause, as in the Apache 2.0 licence).

Made on 2026-10-26. A lawyer should review the final wording before the first public release (tracked in the roadmap).
